# Wear My India (WMI)

Brand website for **WearMyIndia.com** — an Indian clothing house built around origin, craft, and access.

> Wear your roots. Wear My India.

## Brand architecture

The three price and product worlds are named without status-heavy labels:

- **Virasat (विरासत)** — the heirloom collection: rare textiles, exceptional handwork, made-to-order and limited pieces.
- **Kriti (कृति)** — the signature collection: premium craft-led occasion and everyday clothing.
- **Sahaj (सहज)** — the essentials collection: accessible, well-made Indian staples for frequent wear.

Quality, Indian origin, and respect for craft apply to every collection. The tiers differ by rarity, handwork, and time.

## Product principles

1. No imported finished garments.
2. Clear origin and craft notes.
3. Traditional knowledge adapted for contemporary use.
4. Honest value at every price point.
5. Indian material and regional processes wherever practical.

## Technology

- React
- TypeScript
- Vite
- Responsive CSS with no UI framework
- Accessible navigation, dialogs, focus states, reduced-motion support, and semantic structure
